# 足場 是正 集計

住宅工事の足場の是正内容を、是正項目ごとに集計するツール（単一HTMLファイル）。

公開URL: https://jognge12-wq.github.io/ashiba-seisei/

## 使い方（同僚向け）

- LINEワークスで是正写真を見ながら、「是正を入力」タブで該当する是正項目の「＋」を押す
- 現場名・日付・工務店・生産担当を選んで「登録する」
- 「集計」タブで是正項目別・工務店別・月別の集計を確認、PDF出力も可
- 「マスタ管理」タブで是正項目・工務店・生産担当・足場業者の名前を編集
- 作業が終わったら必ず「データ書き出し」→ ファイルを seiun-nx に保存

## 本番化の手順（メモ）

今の GitHub の形のままで本番運用できます。「どこか別の場所に移す」必要はありません。やることは次の通り。

1. **是正項目を本物に差し替え** — マスタ管理タブで、仮の14項目を実際のリストに書き換える
2. **実名を入れる** — 工務店・生産担当・足場業者を、マスタ管理タブで実名に書き換える
3. **モック表示とサンプルを外す** — `index.html` の「モック」案内ブロックと `seedTallies`（サンプルデータ）を削除する（コード作業）
4. **データの置き場所を決める** — seiun-nx のどのフォルダに JSON データファイルを置くか決める
5. **アクセス方法を決める** — モバイル・自宅は公開URL、会社PCは `index.html` をローカルファイルで開く
6. **運用ルール** — 作業後に「データ書き出し」→ seiun-nx に保存、別端末では「データ読み込み」で開く

※ 1・2 は同僚が画面操作だけでできる。3 はコード作業（依頼すれば対応）。

## データの保管について

- 各端末のブラウザ内（localStorage）は「作業用キャッシュ」。ブラウザのデータ削除や端末入替で消えることがある
- **正式な保管場所は、書き出して seiun-nx に置いた JSON ファイル**
- 書き出しファイル名には日付が入る。上書きせず日付ごとに残すと、履歴＝バックアップになる
- ブラウザの仕組み上、seiun-nx への自動保存はできない。「作業後に書き出す」運用が必要

## 更新のしかた（開発者向け）

`index.html` を編集 → `git commit` → `git push`。約1分で公開URLに反映される。
